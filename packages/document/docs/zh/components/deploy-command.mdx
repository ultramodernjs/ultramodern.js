## modern deploy

`modern deploy` 命令，用于生成部署平台需要的产物。

```bash
Usage: modern deploy [options]

Options:
  -c --config <config>  指定配置文件路径，可以为相对路径或绝对路径
  -s --skip-build       跳过构建阶段
  --deploy-target <target>  部署目标（node、vercel、netlify、ghPages、cloudflare），优先于 deploy.target 和 MODERNJS_DEPLOY
  -h, --help            显示命令帮助
```

详细内容可以参考 [部署应用](/guides/basic-features/deploy)。
